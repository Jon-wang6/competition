# 模型数据说明

JSON文件不支持注释，模型数据保持原样。本文件说明每个模型的用途与读取契约。

`architecture` 是输入、隐藏层和输出维数；`features` 的顺序必须与C++特征构造一致。
`parameters` 是按推理器固定布局展开的权重与偏置；`training` 是训练元数据，不是运行时令牌。
模型输出是评分残差，不是正式分数或动作概率；启用开关和修正幅度由YAML与节点参数决定。
